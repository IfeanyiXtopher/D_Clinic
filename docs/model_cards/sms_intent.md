# Model card — SMS intent (`sms_intent_v1`)

## Model details

- **Task.** Classify a short inbound clinic SMS into `confirm`, `reschedule`, `cancel`, `ask_slot`, `stop`, `symptom_or_medical`, `wrong_number`, `unknown`.
- **Type.** TF-IDF (1–2 grams) + logistic regression (`chatbot/classifier.py`). Artifact `chatbot/artifacts/sms_intent_v1.joblib`.
- **Production NLU.** Keyword / phrase rules in four languages (`chatbot/nlu.py`) are the default. The linear model is trained for comparison (Step 5.7). An optional LLM JSON classifier uses `llm/gateway.py` + `nlu_v1` when `LLM_PROVIDER` is set.
- **Why not DistilBERT / Qwen 0.6B.** Both need more RAM than the 1 GB live VPS and a download that the offline clinic bundle cannot assume. The closed intent set is small; a linear model and rules are enough and stay on CPU.

## Intended use

Feed the **dialogue state machine**. The classifier never books, cancels, or answers a clinical question. Tools (`get_available_slots`, `book`, `reschedule`, `cancel`, `record_reply`) are called only from `chatbot/dialogue.py`.

## Out-of-scope uses

- Free-form medical advice or dose changes.
- Identifying a patient (phones are resolved in the channel adapter; the model sees a redacted line).
- Choosing which calendar day to offer — slots are generated in code.

## Training data

Synthetic reminder replies from `data/synth/generate.py` (`SMS_TEMPLATES`) plus extra cancel / confirm lines in `chatbot/classifier.py`. Languages: English, Nigerian Pidgin, Hausa, Yoruba. No real patient messages.

## Evaluation

See `docs/eval_reports/chatbot.md` (regenerated by `make eval-chatbot`). Headline gates: unsafe-response rate = 0, PII-leak rate = 0 on the 150 scripted dialogues. On the synthetic SMS corpus, rules 0.79 vs TF-IDF 0.76 (rules stay the default).

## Limitations

- Typo-heavy live SMS will miss rule phrases; the linear model helps a little, a hosted LLM more so.
- Date hints are parsed by `chatbot/dates.py`, not by the classifier.
- Synthetic only. Retrain on de-identified real replies before a program go-live.
